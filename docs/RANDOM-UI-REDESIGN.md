# 랜덤 뽑기(`random.html`) UI 재설계 스펙

> 기준 문서: `docs/RANDOM-UI-SPEC.md`(현재 동작 명세). 시안: https://claude.ai/code/artifact/c8a58a29-675e-4a69-90aa-4ef8fe19ab56
> 범위: `public/random.html` 한 파일. 백엔드/API 변경 없음. `random-admin.html`은 이번 범위 밖(별도 작업 예정).
> 기능은 현재와 동일하게 유지하고 **배치·진입 방식·히스토리 규칙**만 바꾼다. 아래에 없는 동작은 `RANDOM-UI-SPEC.md` 그대로.

## 1. 레이아웃

### PC (컨테이너 ≥ 960px)
- 2단 그리드: `grid-template-columns: 1fr 420px; gap: 28px; max-width: 1220px`.
- **왼쪽 = 후보 풀**(스크롤 따라 흐름), **오른쪽 = 뽑기 패널**(`position: sticky; top: 24px`).
- 뽑기 패널 구성(위→아래): 인원(1~5) → 위치별 결과 슬롯 → 관계성 → 리롤 2개 → 메인 버튼 → 결과 복사/저장 → 최근 결과 카드 → 캐릭터 설정 전체 / 관계성 전체 링크.
- 기존 `page-hero` 제목·`nav-corner` 홈·우상단 액션 필은 유지. 우상단 "관리자 모드" 라벨은 **"뽑기 설정"**으로 변경(목적지는 당분간 `random-admin.html` 그대로).

### 모바일 (< 960px)
- 1단. 상단 고정 영역(위치 탭 + 출처 스위치 + 필터)은 `position: sticky; top: 0`, 그 아래 후보 풀이 스크롤.
- 뽑기 패널은 **하단 시트**(`position: fixed; bottom: 0`, 상단 모서리 18px 라운드, 손잡이 바).
  - 접힌 상태(기본): 인원 버튼 줄 + 결과 이름 줄 + 설정/관계성 한 줄 + [복사]·[다시 뽑기]·[저장] 줄 + 리롤 2개. 높이 약 260px.
  - 펼친 상태(손잡이 탭 또는 위로 드래그): 최근 결과 목록 추가 노출. 바깥 탭 또는 아래 드래그로 복귀.
  - 후보 풀 하단 패딩을 시트 높이만큼 확보해서 마지막 칩이 가려지지 않게.
- 하단 고정 요소 충돌: personal-nav 원형 버튼과 sync-badge는 하단 시트 안 손잡이 줄 양 끝으로 옮긴다(왼쪽 sync-badge, 오른쪽 위젯 버튼 축소판 28px). 시트 밖에 fixed로 남기지 않는다. PC에서는 위젯이 후보 풀 카드와 겹치지 않도록 그리드 바깥 여백(좌측 32px 컬럼)에 맞춰 위치 조정하거나, 겹침이 남으면 후보 풀 카드에 margin-left를 줘서 피한다. 짧은 페이지에서도 위젯이 콘텐츠 위에 뜨지 않는 것을 확인.

## 2. 위치별 오버라이드 (전면화)

- 위치 탭 라벨에 출처를 **항상** 표시: `공통 · 57` / `위치 1 · 공통` / `위치 2 · 직접 12`. 직접 설정 중인 탭은 보조 라벨을 보라(`--violet`) 배지로.
- 위치 탭 선택 시, 필터 줄 위에 **세그먼트 스위치** `[공통 따르기 | 직접 고르기]` + **[가져오기 ▾]** 버튼을 한 줄로 노출. 기존 `override-bar`(체크박스 + 소스 셀렉트 + "이대로 가져오기")를 대체.
  - "직접 고르기" 선택 = 기존 체크 ON과 동일(공통 복사본으로 시작).
  - "공통 따르기" 선택 = 기존 체크 OFF와 동일. 직접 고른 내용이 있으면 `customConfirm("직접 고른 후보를 버리고 공통을 따를까요?")` 한 번 확인.
  - [가져오기 ▾]는 드롭다운 메뉴(공통 / 다른 위치들)로, 고르면 즉시 복사 + 토스트. "직접 고르기" 상태에서만 활성.
- 읽기 전용 상태 안내문(`pool-readonly-note`)은 제거. 대신 공통을 따르는 위치 탭에서는 칩을 `ch-readonly`로 보여주고 스위치가 "공통 따르기"에 있는 것으로 충분.
- 결과 슬롯마다 출처 배지(`공통 41` / `직접 12`) 표시. 숫자는 **필터 적용 후 실제 추첨 대상 수**.

## 3. 후보 풀

- 필터 줄 오른쪽에 `선택 N / 전체 M` 카운터 + [전체 선택] 토글. 카운터는 현재 탭 기준.
- 오너 헤더: 이름 + `N명 · K 선택` + [전체 선택/전체 해제](현재 상태에 따라 라벨 토글).
- 칩: 기존 `.ch` 스타일 유지하되 `::before`의 `✓ ` 텍스트를 **인라인 SVG 체크**로 교체(이모지/문자 대신 선 아이콘).
- 필터된 칩은 기존처럼 `opacity .25; pointer-events: none`.

## 4. 히스토리 규칙 변경 ★

현재: "뽑기!" 클릭 시에만 한 줄 추가, 리롤은 결과만 바뀌고 히스토리엔 안 남음.
변경: **리롤도 히스토리에 남긴다.**

- "뽑기!" → 새 항목 추가 (`kind: 'draw'`).
- "설정만 리롤" / "관계성만 리롤" → 리롤 결과로 **새 항목 추가** (`kind: 'reroll'`). 기존 항목을 덮어쓰지 않음(리롤 전 조합도 돌아갈 수 있어야 하므로).
- 히스토리 항목 구조: `{ kind, names[], roles[], au, at }`. 표시 텍스트는 기존 복사 포맷과 동일 `이름1(설정1) ✕ 이름2(설정2) / 관계성`.
- `kind === 'reroll'` 항목은 앞에 작은 보라색 `리롤` 배지.
- 최대 개수 20 유지(리롤이 포함되므로 금방 차는데, 당장은 20으로 두고 체감 후 조정).
- 항목 클릭 = 텍스트 복사(기존과 동일). [초기화]는 카드 헤더 오른쪽.
- PC: 최근 결과 카드에 세로 목록. 모바일: 시트 펼침 상태에서만 노출, 접힌 상태엔 헤더 줄에 `최근 N ▸`만.

## 5. 버튼·아이콘

- 메인 버튼 라벨: 결과 없을 때 `뽑기!`, 결과 있을 때 `다시 뽑기`. 스타일은 기존 `.pick-btn` 그라디언트, PC에선 패널 폭 100%.
- 결과 복사 / 저장소에 저장: PC는 아웃라인 필(아이콘 + 텍스트), 모바일은 메인 버튼 양옆 44px 원형 아이콘 버튼.
- 이모지(🎯 📋 💾 🔄 ⚔️ 🌀 🔧 📖)는 전부 인라인 SVG 선 아이콘(16px 그리드, stroke 1.6)으로 교체. 색은 `currentColor`.
- "캐릭터 설정 전체 확인 / 관계성 전체 확인"은 패널 맨 아래 작은 필 2개로 이동. 모달 자체는 기존 리본 모달 유지(이번엔 안 건드림).

## 6. 건드리지 않는 것

- API 호출·폴링·오프라인 폴백·슬롯 애니메이션·색종이·토스트·저장소 선택 모달·필터 배타 규칙·탭별 필터 기억.
- `theme.css` 토큰. 새 색상 리터럴 추가 금지 — 필요하면 토큰 사용.
- 모달(리본) CSS 공용화는 별도 작업.
